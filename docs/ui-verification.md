# UI更新の確認記録

## 対象

ホーム、学び、作品、プロフィールを共通の90年代風デスクトップUIに更新しました。

## 検証結果

- 全4ページをPC幅1440px、スマホ幅390pxで表示確認。
- ホームは幅320pxでも要素位置を確認。
- ヘッダー、スマホのショートカット、スタートメニューによるページ移動を確認。
- 学びで200 Stepsを最小化後、ページ内リンクから復元を確認。
- ホームで最小化後、タスクバーから復元を確認。
- 学びでクラウド設計を最大化し、Escapeキーによる解除を確認。
- スタートメニューの開閉とEscapeキーによるフォーカス復帰を確認。
- 各ページのh1が1個、IDが一意、ローカル参照先・ページ内アンカーが存在することを確認。
- 11教材と3作品の説明・公開先を変更前と照合。フォーマッターによる空白の差は正規化して比較。
- `node --check public/desktop.js`成功。
- PrettierでHTML・CSS・JavaScriptを整形。

## 実装上の配慮

- ボタンに操作内容を示す日本語ラベルを設定。
- 最小化後は復元ボタンへ、復元後は該当ウィンドウへフォーカスを移動。
- キーボードのフォーカス表示と本文スキップを用意。
- JavaScript初期化前は操作ボタンを表示せず、本文と通常のナビゲーションは表示する。
- 窓のドラッグ移動や状態の永続保存は追加していない。
- マウスカーソルはCSSのみで変更し、位置追跡処理は追加していない。
- 外部サービス側の動作・可用性は今回のUI検証対象外。

## PC画面固定の追加変更（2026-09-12）
