# 配色の参考サイト一覧（ドット文字・ピクセルアートの気配を「少しだけ」）

2026-09-03調査。URLはすべてHTTP 200を確認済み。色は各サイトを実際に読み込み、背景色・文字色を面積加重で集計した上位色（目視の補正あり）。

## 選定の観点

- ピクセルアートやレトロゲームが本業なのに、サイトのUI自体は現代的（角丸・余白・可読性）で「寄せすぎていない」もの
- ドット要素の使いどころが1〜2箇所に絞られているもの（見出し書体だけ、ロゴだけ、素材画像だけ）
- 好きなIP（デジモン）は「色だけ拝借」できる公式サイトを入れた

## ドット文字のフォント資源（見出しやラベル限定で使う）

- [DotGothic16（Google Fonts）](https://fonts.google.com/specimen/DotGothic16)：日本語対応のドットゴシック。`<link>`一本で使える。見出しラベル（PICK UP等）だけに当てるのが一番効く
- [美咲フォント](https://littlelimit.net/misaki.htm)：8×8ドットの日本語フォント。ロゴやファビコンの文字向き
- [PixelMplus](https://itouhiro.hatenablog.com/entry/20130602/font)：M+ベースの8bit風フリーフォント。10px/12pxの2種

## 「寄せすぎない」ための決めごと

- ドット要素は1箇所に絞る（候補：見出しラベルのフォントをDotGothic16にする／ファビコンとロゴだけドット／ホバー時のアイコンだけドット）
- 写真・図・本文は絶対にドットにしない。角丸・余白・行間は今のまま現代的に
- 8bit書体は本文に使わない（Undertaleが「寄せた側」の上限）
- 色はLospecのパレットから3〜5色だけ拾い、背景は白かクリームかごく暗い紺のどれかに固定する
