学習サービス目次

すべて個人で開発・運用している学習Webサービスの入口です。 ブラウザだけで始められるステップ形式の教材と、 クラウド設計をケースで学ぶ教材、そして開発ブログをまとめています。

公開12サービス

01

200 Stepsシリーズ

プログラミング言語をブラウザ上で書いて、その場で実行しながら学ぶステップ形式の教材シリーズ。 環境構築は不要で、1ステップずつ手を動かして進められます。

公開7

  1. C++ 200 Steps 言語 ↗ C++を基礎から学ぶステップ教材。ブラウザ上で書いて、その場で実行できる。
  2. Rust 200 Steps 言語 ↗ Rustを基礎から学ぶ200ステップ。所有権もコードを動かしながら身につける。
  3. Go 200 Steps 言語 ↗ Goを基礎から学ぶ200ステップ。シンプルな文法を順に書いて確かめる。
  4. PHP 200 Steps 言語 ↗ PHPを基礎から学ぶ200ステップ。Webでよく使う書き方を実行しながら学ぶ。
  5. JavaScript 200 Steps 言語 ↗ JavaScriptを基礎から学ぶ200ステップ。ブラウザの言語をブラウザで学ぶ。
  6. Stimulus 200 Steps フレームワーク ↗ JavaScriptフレームワークStimulusを基礎から学ぶ200ステップ。
  7. Python 200 Steps 言語 ↗ Pythonを基礎から学ぶ200ステップ。エラーを読んで直す50問つき。
02

アーキテクチャ学習

要件からクラウドの構成を考える教材シリーズ。 サービスの暗記ではなく、「この課題ならどう組むか」をケースで学びます。

公開3

  1. AWS Architecture Patterns クラウド ↗ ケースで学ぶAWSアーキテクチャ。要件を読み、構成を考えてから解説で確かめる。
  2. Cloudflareアーキテクチャ入門 クラウド ↗ Cloudflareの主要サービスとアーキテクチャパターンを、公式ドキュメントベースで学ぶ。
  3. GCP Architecture Patterns クラウド ↗ ケースで学ぶGCPアーキテクチャ。Cloud RunやBigQueryを軸に50ケースで構成を考える。

セキュリティ

Webアプリケーションを守る側の視点を学ぶシリーズ。攻撃の仕組みと修正コードで学びます。
